# Security (pre-release)

No released versions exist. When private vulnerability reporting is enabled, use that channel; never disclose company PCB datasets in public Issues. Threat model includes malformed archives/XML, traversal and decompression bombs, corrupt connectivity and port mapping, stale solver cache, incomplete run snapshots, file integrity and unintended data disclosure. BoardSI must run offline; no automatic uploads, telemetry or external cloud solvers. Gitignore and secret scanning alone do not protect confidential CAD files.
