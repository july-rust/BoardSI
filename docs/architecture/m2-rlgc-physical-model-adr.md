## 1. Evidence boundary and exclusions

The existing `boardsi-numerics` accepts **external scalar** R [Ω/m], L [H/m], G [S/m], C [F/m] and returns one uniform 2-port complex S point for one real positive equal port reference. Its 180 independent high-precision ABCD mathematical cases and native-platform runs verify *that numerical mapping*, not geometry-to-RLGC or PCB physics. `ModelStatus::Validated` is not currently issued; successful samples are physically `Approximate`. Lossy nonzero-length DC is unsupported. No frequency-dependent conductor/dielectric extractor, multiconductor matrix engine, S4P/mixed-mode export, verified via/pad response, or product-level PCB accuracy exists. `boardsi-model` is a canonical data/integrity prototype, not an EM mesh engine. `boardsi-ipc` and Qt are transport/UI prototypes, not physical solvers. See [numerical contract](numerical-contract.md), [numerical evidence](../validation/m0-numerical-foundation.md), [native Qt evidence](../validation/m0-qt-runtime-followup.md). Existing code is **not changed** in this ADR.

Do not substitute a perfect via, zero dielectric/conductor loss, infinite return plane, missing mask, or synthetic coupling for an unknown physical feature and present the output as an ordinary validated path. Explicitly idealized analytical *test coupons* are different from real-board results. Geometry/Port provenance is independent of the imported file type: ASC, ODB++, IPC-2581 etc. normalize to the same canonical geometry. A successful import or GUI run never certifies EM accuracy.

## 2. Candidate comparison — engineering judgement, not benchmark results

| Method | Geometry/material scope | Accuracy prospects and known limitations | Engineering effort / compute | License and reproducibility | Decision |
| --- | --- | --- | --- | --- | --- |
| Closed-form quasi-TEM microstrip/stripline approximations | Idealized, fixed configurations and ranges; finite thickness corrections only when formula supplies them | Efficient cross-check and rough feasibility. Real finite planes, multilayer stackups, mask, trapezoid or coupled asymmetry may violate assumptions; formula-dependent error/band **not qualified** | Low; negligible CPU/RAM | Mathematical formulas must be sourced/versioned; implementation independently audited | **Use as sanity/oracle only** within published assumptions; not universal extraction |
| 2D quasi-electrostatic finite-element method (FEM) | Parameterized cross-sections; layered ε, air/mask, real thickness, finite reference-conductor cross-sections and coupled conductors | Direct field-based **C**, and ideal exterior **L** through vacuum-reference solve for nonmagnetic media; boundary/mesh/material uncertainties remain. Electrostatics by itself **cannot** provide complete lossy R,L,G vs frequency | Medium-high; mesh and sparse system dominate RAM and CPU | In-house implementation preferred for initial product; third-party solver licenses reviewed separately | **Preferred architecture**, not validated production model |
| 2D boundary-element method (BEM) | Excellent conductor-surface representation; complicated dielectric interfaces require careful Green functions/volume/interface treatment | Alternative cross-check, may provide efficient open geometries; layered dielectrics and dense matrix conditioning are nontrivial | Medium-high; potentially dense O(N²) memory | Exact library and redistribution terms PENDING | **Alternative/reference**, not selected |
| 2D AC magnetic/diffusion + dielectric-loss field solve | Frequency-dependent conductor currents and dielectric material loss | Necessary to capture R(ω), conductor internal L(ω), skin and proximity; quasistatic, surface-impedance and thin/thick limits require validation | High, frequency/mesh-dependent | Standalone design needed; no adopted library | **Required extension before claiming lossy RLGC** |
| Full-wave 3D EM or de-embedded coupon measurements | Bends, transitions, return switching, higher-order modes | Reference evidence for selected cases, not a 2D drop-in nor product implementation | Expensive in CPU, memory, setup and/or equipment | Proprietary entitlement or independent measurement; redistribution permissions PENDING | **External cross-check only** |

No method is declared accurate to 30 GHz simply because the frequency input permits 30 GHz. Its supported band is geometry-, material-, excitation-, boundary- and validation-specific. 2D quasi-TEM requires longitudinally uniform cross-section and no relevant higher-order or 3D discontinuity; classify violations before numerical solving. See [Ansys 2D notes](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Q3DExtractor/Content/Q3D/2DExtractorTechnicalNotes.htm?TocPath=Q3D+Extractor+Help%7C2D+Extractor+Technical+Notes%7C_____0), [Ansys field solvers](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Q3DExtractor/Content/Q3D/SolvingforFieldsfor2DExtractor.htm), and [multilayer FEM research](https://doi.org/10.1002/mop.23750).

## 3. Recommended staged physical model

**D-01 (architecture direction):** Implement a **2D quasi-electrostatic FEM cross-section extractor** first, with independent **physical** evidence gates. Build from canonical layer z, trace/pad copper cross-section, finite conductor thickness and shape, mask/air, material regions, conductor IDs and explicitly selected reference conductors. Use sparse assembly, exact units, bounded domains, convergence studies, and reproducible meshing. Do not integrate a product dependency merely on basis of this ADR.

For each active signal conductor i, apply 1 V to i and 0 V to all other defined signal/reference conductors; solve ∇·(ε∇φ)=0 for the modeled dielectric domain under documented exterior boundary conditions; integrate conductor charges or field energy to recover the **Maxwell** capacitance-per-length matrix C with Q=C V. Apply the same geometry with every dielectric replaced by vacuum permittivity ε0 to obtain **C0**. For perfect conductors and *nonmagnetic*, quasi-TEM external field approximation:

`L_ext = μ0 ε0 (C0)^(-1)`

where C0 is the grounded, reduced signal-conductor matrix (not a nodal matrix with a null reference mode). **Solve** positive-definite systems / factorizations; do not compute a numerically unstable explicit inverse. This is an exterior/PEC quasi-TEM inductance, **not** a model of internal conductor inductance, resistive losses or frequency-dependent proximity currents. If topology, reference or matrices are degenerate, refuse rather than pseudo-invert silently. Use exact dimensions and σ, ε provenance with named ranges.

**D-02 (staged capability, no misleading 'RLGC PASS'):**
1. **Field foundation:** single uniform, straight, nonmagnetic microstrip with known reference, grounded plane geometry, ideal PEC and explicitly lossless dielectrics; calculate C and L_ext. May be a *lossless-only analytical coupon* until independent geometry validation. Distinguish this scoped capability from physical lossy RLGC.
2. **Single-ended expansion:** verified symmetric and asymmetric stripline, layered dielectric, finite metal and mask/air. Each topology and material envelope is separately qualified. A 2D solver can model finite-width return copper *if longitudinally uniform*; it cannot infer a longitudinal plane slot/cutout or via-mediated return.
3. **Finite-conductivity full RLGC:** add independently checked R_dc and magnetic-field/diffusion extraction of R(ω), L_int(ω) with skin/proximity and finite return conductor; add dielectric AC loss G(ω), separate leakage at DC, and documented dispersion. Do **not** simply set unspecified R or G to 0.
4. **Coupled signal conductors:** solve the entire cross-section at once to obtain full C0/C and, after magnetic/loss validation, R,L,G coupling matrices; calculate full physical 4-port and mixed-mode. No mutual terms estimated from two independent single-ended runs.
5. **Composite routes:** only after boundary and segmentation reference tests, connect independently validated uniform sections; unmodeled discontinuities remain Unsupported.

### Required cross-section input

- Per-slice geometry in metres: trace and ground widths, thickness, copper cross-section profile (rectangular/trapezoidal provenance), gaps, layer heights, dielectric interfaces, air domain, mask, finite planes and conductor overlap/short detection.
- Material regions: positive permittivity and its frequency applicability, loss angle or conductivity with frequency/temperature metadata where supplied; copper σ, μ, roughness data/model, validity band.
- Electrical: reference-conductor identity and connectivity, possible floating conductors (**explicit solve/boundary or Unsupported**), positive return continuity along the studied length, port/signal conductor mapping.
- Numerics: meshing policy/element order, adaptive tolerance, enclosing-domain type and distance, basis/order, solver residuals, condition estimates, backend/version and units.
- Provenance: normalized source feature IDs, user scenario changes, source revision and material dataset. Model ID/algorithm version participates in cache identity.

Refuse material fill-by-default, ground-plane assumptions or silent dropping of air/mask/finite thickness. Optional mask must be explicitly "absent" or an explicit idealized assumption, never inferred from missing data. Initial inhomogeneous dielectric approximations must be tagged with their assumptions.

## 4. Multiconductor equations and port contract

For n explicitly referenced signal conductors, use the **conductor voltage and current representation** relative to the selected reference(s), with all four matrices n×n in SI per length. Convention remains exp(+jωt), positive +x propagation, input current orientations documented:

`∂V/∂x = -Z(ω)I;quad ∂I/∂x = -Y(ω)V`

`Z(ω)=R(ω)+jω L(ω);quad Y(ω)=G(ω)+jω C(ω)`.

The Maxwell C matrix maps charges to voltage and is *not* a matrix of positive pairwise lumped capacitors. For reduced grounded Maxwell C, off-diagonal mutual entries are typically negative, diagonal entries positive. In a grounded lumped branch convention, `C_branch(i,j)=-C_Maxwell(i,j)` for i≠j and `C_to_ground(i)=Σ_j C_Maxwell(i,j)` **only if** the specified reference/conductor reduction and all other ideal assumptions match. Equivalent details for G require material/conduction consistency; arbitrary component sign-flipping is prohibited. The **telegrapher equations use the Maxwell nodal capacitance/admittance matrix** in the declared voltage/current basis, not an undocumented SPICE-branch conversion. Reference changes and floating conductor elimination must use defined matrix reduction and record the effective network.

Basic physical checks for passive, reciprocal, supported configurations: real symmetric R,L,G,C within numerical tolerance (where the underlying material and basis are reciprocal); R,G positive semidefinite, and positive-definite reduced C,L for a well-referenced nondegenerate ideal line; numerical energy checks. Individual off-diagonal signs are **not** by themselves passivity criteria. Nonreciprocal or active materials are out of the first scope. Numerical condition / eigenvalue thresholds remain PENDING until reference experiments.

**Prohibited:** `sqrt(Z_ij/Y_ij)` or element-wise square roots for individual conductor/mutual entries, or independently constructed coupled S blocks. Coupled propagation follows the *matrix* telegrapher system, e.g. a 2n×2n first-order state generator `[[0,-Z],[-Y,0]]`, with a numerically stable boundary scattering solve, not a naïve unbounded `exp(+γl)` chain. Choice among matrix-exponential/scattering boundary algorithms, scaling, conditioning and semidefinite corner cases is **PENDING** independent comparison. An arbitrary matrix square root/diagonalization is not automatically a valid power-wave normalization.

**Port basis (2-conductor coupled pair):** physical order `[near_P,near_N,far_P,far_N]` is proposed as canonical export order, with explicit 1-based ports [1,2,3,4], direction near→far and P/N polarity. Within each end, modal voltage basis `Vd=Vp-Vn`, `Vc=(Vp+Vn)/2`; power waves for equal real 50 Ω per physical port use an orthonormal differential/common transform, `(1/√2)[[1,-1],[1,1]]` on appropriately normalized incident/outgoing waves. Corresponding reference impedances are **100 Ω differential, 25 Ω common** (equal 50 Ω physical reference; no independent assertion that modal impedances of an asymmetric physical line have these values). Preserve 4×4 S first; create `Sdd, Sdc, Scd, Scc` only with fixed grouping/order and normalized reference; test the inverse transform. Unequal/complex reference impedances require a separate generalized power-wave definition and are **initially Unsupported**, not handled by a simple unitary transform. Pair polarity reversal changes signs in cross-mode components; do not relabel by heuristic after solve. Even/odd independent propagation is permitted only when symmetry/common modal basis genuinely decouples the equations (including losses); a geometrically or electrically asymmetric pair must retain mode conversion. Consult [scikit-rf generalized mixed mode contract](https://scikit-rf.readthedocs.io/en/latest/api/generated/skrf.network.Network.se2gmm.html), [port ordering example](https://scikit-rf.readthedocs.io/en/latest/examples/mixedmodeanalysis/Mixed%20Mode%20Basics.html) and [NIST asymmetric coupled-line characterization](https://www.nist.gov/publications/multiconductor-transmission-line-characterization).

Physical S passivity in correctly normalized real positive port power waves: `σ_max(S) ≤ 1+tol`; reciprocity `||S-Sᵀ||` in a documented consistent norm. **All complex entries** and both directions must be compared. Positive semidefinite R,G checks do not replace frequency-by-frequency network passivity, and sampled passivity alone is not an all-band causal proof. No automatic "repair" may overwrite physical predictions. Preserve error category and no fabricated S data.

## 5. Loss, DC, and physical bandwidth — deliberate staged gates

| Phenomenon | Planned physics and caveat | Earliest trustworthy status |
| --- | --- | --- |
| PEC lossless line | Explicitly ideal conductor (R=0) and *explicitly* lossless dielectric (G=0) as a benchmark, not default for an imported PCB | Validated **only for that declared ideal coupon** after independent field/boundary tests; otherwise Approximate or Not Run |
| DC resistance | From σ and exact conductor/return cross-section for a longitudinally uniform path, with network boundary/leakage constraints; not a GHz skin formula extrapolated to f=0 | Unsupported until a separate DC field/continuity benchmark |
| Skin effect | Frequency-dependent current diffusion; surface impedance limit if δ ≪ conductor dimensions and assumptions validated | Unsupported until R(ω)/L_int(ω) independently matched |
| Proximity/return current | Joint magnetic solve for coupled current crowding and finite reference conductor; no isolated-trace sum of losses | Unsupported until coupled magnetic solver qualified |
| Dielectric RF loss | Complex ε(ω) or field-energy/loss integration and physically defined G(ω). `ω C tanδ` only in its justified homogeneous-field approximation, not universal multilayer rule | Unsupported until per-layer and dispersive benchmarks |
| Dk/Df dispersion | Measured tabulation or causal model (Debye / Djordjevic-Sarkar candidate), calibrated and band-limited; no guessed broad-band constant-fit certificate | Approximate when declared assumption permitted; otherwise Unsupported out of band |
| Roughness | Geometry/surface impedance correction with model applicability and independently documented parameters | Unsupported; no automatic roughness multiplier |
| Higher-order / 3D return | Quasi-TEM and longitudinal-uniformity check; compare full-wave reference for complex cross-section and high f | Unsupported outside per-model verified interval |

Skin depth diagnostic for a good, uniform, nonmagnetic conductor: `δ≈sqrt(2/(ω μ σ))`; it is **not** a full internal impedance/proximity model. The AC surface-resistance high-frequency expression is likewise not a DC prescription. DC leakage is **not** inferred from an RF loss tangent. Broadband material ε′/ε″ consistency and causality require separate investigation; see [NIST dielectric metrology](https://www.nist.gov/publications/microwave-dielectric-property-measurements), [NIST packaging conductor/dielectric loss](https://www.nist.gov/publications/dielectric-and-conductor-loss-characterization-and-measurements-electronic-packaging) and [Ansys causal-material settings](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Q3DExtractor/Content/Modeler/DesignSettingsfor2D.htm).

User-selectable **DC to 30 GHz is a sweep request range, not supported accuracy**. Every sample is independently checked against structure, material calibration band, subwavelength quasi-TEM requirement, conductor loss model and validation evidence; the supported upper frequency is **PENDING**. Do not invent a universal `f_max` or hard-coded width/wavelength threshold without comparisons. Unsupported points must not be interpolated or changed to ideal thru for exporting a "complete" model.

## 6. Model state is not execution/test status

- **Validated**: specific *model ID + topology + dimensions + material dataset + boundaries + ports + frequency band* has independent physical benchmark, stated error/uncertainty and convergence proof, and current scenario is inside that qualified envelope. Cannot inherit scalar mathematical `boardsi-numerics` PASS as evidence.
- **Approximate**: explicit bounded simplifying assumption or out-of-reference configuration **only when an approximate calculation is itself meaningful, authorized and clearly documented**. It is not a catch-all fallback for missing required EM effects; separate numerical PASS and uncertainty/assumption details.
- **Unsupported**: missing required material, incorrect/unknown reference return, invalid floating conductor or topology, longitudinal cutout, unverified via/pad/bend, unmodeled conductor loss for a requested real lossy result, unqualified DC/higher-order case, or model range breach under strict settings. Return reasons and **no complete S**.

Other independent axes: Not Run/PASS/FAIL for **tests**, execution success/error, convergence status, user limit verdict, and input provenance/confidence, as in specification §§10,13. Do not collapse these into a single PASS label.

## 7. Resource / deterministic reproducibility requirements

A 2D FEM electrostatic solve performs one linear problem per independent conductor excitation plus a vacuum run, with shared matrix factorization where possible. Let N be mesh unknowns, n active signal conductors and F distinct material-frequency states. Assembly/storage scales with mesh sparsity, while sparse factorization, n right-hand sides and frequency-dependent rebuilds determine measured wall time and peak resident RAM. **No quantitative complexity, GHz runtime or PC budget is claimed before benchmarks.** Batch excitations, reuse mesh where permissible, and explicitly invalidate dielectric-matrix caches when ε changes. Frequency-independent geometry and C0 may be reusable; loss/dispersion changes require updated R/L/G/C. Abort and memory ceilings use existing Worker isolation, not GUI-thread computation. Record every elapsed time, peak RSS, mesh count, boundary size, residual and provenance in the test receipts.

Mesh tests: refine locally at trace corners/mask interfaces; compare capacitance, L, impedance, wave velocity, full S, reciprocity and energy. Enlarge exterior air box / alternative asymptotic boundary separately to detect boundary truncation bias; convergence of *only one* mesh on a fixed small box is not sufficient. Explicit sign/units and metal topology checks must precede mesh generation.

## 8. Dependencies, licensing, and unresolved decisions

- **Independent reference candidates:** mathematical TEM/telegrapher closed form, an independently implemented FEM field problem (e.g. FEniCSx/DOLFINx) or qualified commercial 2D extractor, external measured/de-embedded uniform coupons. An oracle cannot be merely the same routine called twice. Independent FEM uses a separately written weak form and mesh workflow, not BoardSI's output as its own truth. Physical benchmark qualification still **PENDING**.
- **scikit-rf**: BSD-3-Clause open-source candidate **only for independent network conversion and Touchstone oracle**; record version, licenses and transformation convention if used. [Official license](https://github.com/scikit-rf/scikit-rf/blob/master/LICENSE.txt).
- **DOLFINx**: LGPL-3.0-or-later candidate for independent reference electrostatic FEM, **not yet adopted** in product nor validated as turnkey RLGC solver. Dependencies and actual link/distribution implications require review. [Official license](https://github.com/FEniCS/dolfinx/blob/main/README.md).
- **openEMS**: GPL-3.0 external full-wave cross-check candidate, **not** intended to be linked, bundled or copied into product absent legal review. Availability is not proof that a reference is appropriate. [Official repository/license](https://github.com/thliebig/openEMS).
- **Ansys 2D Extractor/HFSS**: proprietary reference if a valid local license exists; generated data redistributability, settings, port reference and version must be checked. [Ansys technical scope](https://ansyshelp.ansys.com/public/Views/Secured/Electronics/v252/en/Subsystems/Q3DExtractor/Content/Q3D/2DExtractorTechnicalNotes.htm?TocPath=Q3D+Extractor+Help%7C2D+Extractor+Technical+Notes%7C_____0).

**Pending / do not silently freeze:** exact FEM formulation and mesher/library/license for production; finite-conductor magnetic R/L method; lossy DC network boundary; multiport stable scattering algorithm; field-domain and mesh stopping thresholds; validated error metric/tolerance for physical RLGC and S; exact shape and physical f_max for each material/topology; test hardware/CPU/RAM budget; external reference entitlement/dataset licenses; baseline 2D/3D coupler fixtures. Resolve at M2 implementation/qualification gates (§15); this document records a recommended path, **not implementation authorization to claim physical Validated**.

## 9. Minimal M2 implementation sequence (outside this PR)

1. Source-lock an independently generated lossless single microstrip/stripline reference, analytical TEM anchor and mesh/boundary error study; define typed cross-section and model provenance.
2. Implement **lossless 2D electrostatic C/C0 + exterior L** for *one* straight microstrip. Qualify vs external field/closed-form within a documented restricted domain; report uncertainty and status. No forced `Validated`.
3. Generalize cross-section to symmetric/asymmetric stripline and layers/mask/finite returns; run mesh/domain studies.
4. Add DC and frequency-dependent conductor R/L_int, dielectric G/dispersion in independently validated order; block true-PCB lossy output until supported.
5. Implement joint 2-conductor matrices, stable coupled multiport S, 4-port/mixed-mode, asymmetric mode-conversion and independent passivity checks.
6. Integrate verified extractor into `boardsi-numerics` only via a **new typed interface** preserving the existing scalar API and its 180-reference regression baseline. Connect canonical model and Worker without Qt changes where possible; run product test gates and explicitly documented native-platform benchmarks.

**Change discipline:** This 6th task is documentation-only. No tests run; no solver, Qt, IPC, existing specification, workflow, or fixture modified. No issue closed and no PR automatically merged.
