# Contributing

BoardSI is at planning/M0. Use short-lived branches and PRs, trace changes to requirement IDs (Uxx) and acceptance test IDs (Txx), and record reproducible validation. Mark a model or importer Validated only after independent evidence. Avoid proprietary PCB data, confidential results, private paths and unreviewed sample licenses in commits, logs, Actions and public releases. Technical units follow SI conventions. Require actual three-platform native build/runtime checks before any public binary release.
